Admin Portal Overview

Centralized Control for School Operations

Presented by SEALE J.R

The Admin Ecosystem

The Admin Portal is the command center for the entire digital platform, providing tools for:

  • User Management: Learners, Educators, and Parents.
  • Data Integrity: SA-SAMS integration and record keeping.
  • Academic Oversight: Grades, Reports, and Attendance.
  • Communication: School-wide announcements.

SA-SAMS & Learner Management

Streamline the admissions-to-enrollment pipeline:

  • Accepted Applications: View and finalize imported learner registrations.
  • Active Learners: Filter by grade/class, export lists to Excel/PDF.
  • Duplicate Detection: Automated tools to find and remove duplicate entries.

LMS Dashboard

Class & Grade Assignment

Efficiently organize the school structure:

  • Class Assignment Tool: Bulk-assign learners to specific sections (e.g., 4A, 4B).
  • Unassigned View: Quickly identify learners who need class allocation.
  • Grade Sections: View comprehensive lists of learners per grade level.

Academic Administration

Mark Sheets

Generate official mark sheets for any class and subject based on teacher inputs.

Report Cards

Generate and publish detailed learner report cards for any term with a single click.

Attendance Monitoring

Keep a pulse on school attendance:

  • Weekly Records: View aggregated attendance data submitted by teachers.
  • Absence Tracking: Identify patterns in learner absenteeism across terms.
  • Filtering: Drill down by Year, Term, Week, and Class.

Communication & Announcements

Manage the flow of information:

  • Announcements: Create, schedule, and publish news to the website and portals.
  • Parent Data: Access comprehensive contact lists for parents, filtered by grade or class.

Calendar & Scheduling

Set the rhythm for the academic year:

  • Official Calendar: Define term dates, holidays, and major school events.
  • Synchronization: Updates here automatically reflect on Teacher, Parent, and Learner portals.

System Maintenance

Tools to keep the platform running smoothly:

  • Database Organization: "Rebuild Class Views" to optimize Firestore data structures.
  • Educator Management: Manage staff profiles and assignments.

Empowering Administration

The Admin Portal reduces manual workload, ensures data accuracy, and provides the insights needed to lead effectively.
